# バンコマイシン（VCM）投与設計支援ツール

バンコマイシン（Vancomycin: VCM）の初期投与量および維持用法用量を、患者背景（成人・小児）や薬物動態（PK）パラメータに基づいて自動計算・シミュレーションする単一ファイル構成（Single File）のWebアプリケーション。

外部サーバーやインターネット接続を一切必要としない完全オフライン動作（Vanilla JS）設計となっており、病院内の電子カルテ端末や共有フォルダ上から安全かつ高速に起動・利用可能。

---

## 主な機能

- **成人 / 小児モードの自動切り替え**
  - **成人モード:** Cockcroft-Gault式に基づくCLcr（クレアチニンクリアランス (mL/min)）評価および 2-コンパートメント点滴静注モデルによるAUC（24h）・トラフ値計算。
  - **小児モード:** 生後日齢・月齢からの換算、小児用特定パラメータ（1-コンパートメントモデル）によるトラフ値推算・逆算。
- **2つの設計アプローチ**
  - **プロトコル推算モード:** 院内ルールやCLcr区分に基づく投与量・投与間隔の自動割り出し。
  - **目標指標からの逆算モード:** 目標AUC（成人：例 480）または目標トラフ値（小児：例 13 $\mu\text{g/mL}$）からの逆算用量設計。
- **リアルタイムPKシミュレーション**
  - 1回投与量や投与間隔（$\tau$）、点滴時間（$T_{\text{inf}}$）を手動調整した際、定常状態におけるAUCおよびトラフ値を即座に再計算。
- **肥満患者・高齢者・腎障害患者への安全対策（ガード機能）**
  - BMI 25以上の肥満患者に対する補正体重（ABW (Adjusted Body Weight)）の自動適用および初期投与量（25 mg/kg、最大3000 mg）の補正。
  - Serum Creatinine (Scr) 0.6 mg/dL 未満の繰り上げ処理（小児は年齢依存の下限式を適用）。
  - 成人モードにおける 15歳以下入力に対するエラーブロック。
  - 投与間隔が点滴時間以下になるような論理的破綻に対するバリデーション。
- **カスタマイズ可能なプロトコル設定 (LocalStorage)**
  - CLcr区分の増減、用量計算式（固定値 vs 体重比例）、刻み幅（100 mg / 25 mg / 10 mg等）を画面上の「プロトコル設定」タブから自由に書き換え・保存可能。

## 採用している薬物動態（PK）パラメータ・計算式

### 1. 成人モデル（2-コンパートメント点滴静注モデル）

- **CLcr (mL/min):** Cockcroft-Gault式
  $$\text{CLcr} = \frac{(140 - \text{年齢}) \times \text{計算用体重}}{72 \times \text{Scr}} \quad (\text{女性は} \times 0.85)$$
  * ※Scr $< 0.6$ の場合は $0.6$ として計算。
  * ※BMI $\ge 25$ の場合：$\text{計算用体重} = \text{ABW} = \text{IBW} \times 0.6 + \text{実体重} \times 0.4$ （$\text{IBW} = 22 \times \text{身長(m)}^2$）

- **全身クリアランス (CL):**
  $$\text{CL (L/h)} = 4.9 \times \left( \frac{\text{CLcr}}{120} \right)^{0.959} \quad (\text{CLcr} > 167.8 \text{ の場合は } 167.8 \text{ で固定})$$

- **分布容積 & 速度定数:**
  $$\text{Vc (L)} = 32.1 \times \left( \frac{\text{体重}}{60} \right)^{0.532}, \quad \text{Vp (L)} = 58.2 \times \left( \frac{\text{体重}}{60} \right)^{0.348}, \quad \text{Q (L/h)} = 8.33$$

- **AUC (24h):**
  $$\text{AUC} = \frac{1\text{日投与量 (mg)}}{\text{CL (L/h)}}$$

### 2. 小児モデル（1-コンパートメント点滴静注モデル）

- **Scr下限値 (mg/dL):**
  $$\text{Scr}_{\text{min}} = 0.209 \times \left( \frac{\ln(\text{生後日齢})}{6.59} \right)^{2.067}$$

- **クリアランス (CL) & 分布容積 (Vd):**
  $$\text{CL (L/h)} = 0.198 \times \text{体重}^{0.75} \times \left( \frac{0.4}{\text{Scr}} \right)^{0.597} \times \left( \frac{\ln(\text{生後日齢})}{6.59} \right)^{1.829}$$
  $$\text{Vd (L)} = 0.636 \times \text{体重}$$

## 使い方・セットアップ

本アプリは外部依存のない単一の HTML ファイル (`vcm_calculator.html`) として構築されている。

1. **ローカル環境で起動する**
   - リポジトリから `vcm_calculator.html` をダウンロードする。
   - ファイルをダブルクリックして、Google Chrome, Microsoft Edge, Safari などの主要ブラウザで開く。
2. **共有フォルダ（NAS/Windows共有）から利用する**
   - 院内のネットワーク共有フォルダに `vcm_calculator.html` を配置する。
   - 複数の端末から同時に参照・開いて使用可能（相互の入力データは干渉しない）。

## 設定の保存とプロトコルの統一について

- **ユーザー設定の保存:**
  「プロトコル設定」タブで変更した設定値（投与量の刻み幅やCLcr区分ルールなど）は、アクセスしているブラウザの `localStorage`（ローカルストレージ）に自動保存される。
- **組織（院内）プロトコルの統一手順:**
  全端末・全ユーザーで初期表示されるデフォルトプロトコルを統一したい場合は、`vcm_calculator.html` 内の JavaScript ソースコード冒頭にある `defaultConfig` オブジェクトのパラメータを直接修正してからファイルを配布・配置すること。
